# 냉장고 위젯 외형 다시 적용

사용자는 e982abf6 공개 위젯이 시안과 다르다고 지적한 뒤 “아니 냉장고 위젯 다시해”라고 요청했다. 직전 동선 구현의 기능 통과를 외형 완료로 취급한 판단을 정정한다. 이번 작업은 냉장고 위젯과 부엌 화면의 실제 외형을 고친다. 함께 첨부된 금융 위젯은 수정 대상이 아니다.

기준은 [Nov4 재료 시안](../designs/kitchen-full-flow-20261104/01-ingredients.png)과 [성장·부엌 시안](../designs/kitchen-full-flow-20261104/04-growth.png)이다. 새 동작 보드를 다시 그려 대체하지 않고 실제 앱의 사진 자산·좌표 투영·CSS와 생성 전달물을 수정했다.

## 실제 변경

- 열린 냉장고는 분홍·샴페인 조명과 두꺼운 금속 테두리를 밝은 흰색 본체/중립 조명으로 교체했다. 홈의 그림에 여백을 주고, 뒤의 부엌을 과하게 확대하던 합성을 정리했다.
- 실제 음식13종·양념4종의 그림을 작은 흰 정리함과 얕은 냉동 트레이로 교체했다. 기존 재료 이름·수량·좌표·기한을 채우거나 늘리지 않았다. 미입력 영양은 미입력으로 남긴다.
- 닫힌 부엌은 실제 비율0.604인 새 슬림 냉장고 원본을 사용한다. 방 너비의28.5%로 놓아 양쪽 조리대·창문·식물·액자가 함께 보인다. 기존 넓은 본체를 가로로 찌그러뜨려 맞추지 않았다.
- D1/D5/D6은 2:1 방 사진을 쓰고 내용 높이에 맞춘다. 꾸미기/적용의 사진·가구 바닥·조리대와 소품 투영을 공유하며 사진 아래의 빈 베이지 띠를 없앴다. 완료 안내는 사진을 덮지 않는 별도 행이다.
- 홈·상세 화면은 위쪽8px부터 같은 기준선으로 연다. 모바일에서530px카드가157px 아래로 떠 있던 중앙 정렬을 제거했다. 재료/영양제 아래 시트는 실제 메인 프레임 바닥에 맞춘다.
- 영양 숫자와 라벨의 대비/간격을 정리했다. 소품·설정 버튼은 중복된 배경/정리함 항목을 하나의 기존 설정 폼으로 연결하며, 실제 조작은44px 영역을 유지한다.

모든 원본 시안과 이전 사진은 보존한다. `miniature-kitchen-preview-v1` version1, 재고·계획·식사·실제 지출·보상 원장은 바꾸지 않는다. 카메라와 그림 크기는 표시 계산이며 저장 좌표를 마이그레이션하지 않는다. 기존 첫 기록 보상과 적용 때의 소유권/꾸밈권 확정 규칙도 유지한다.

## 확인 기준

같은 저장 자료와 뷰포트의 전후 실제 화면을 비교한다. 핵심 기준은 열린 냉장고 주변 여백, 방 너비28.5%인 슬림 앞면, 양쪽 조리대와 액자/창문이 보이는2:1구도, 흰색/밝은 우드 색감, 실제 음식 정리함 크기와 읽을 수 있는 요약, 적용 전후 소품의 같은 조리대 관계다. 캡처 수나 모델 검사 통과만으로 사용자 디자인 승인을 대신하지 않는다.

기본 검증은 320×568·390×560·801×782의 A1/A5/D1/D5/D6과390×844 첫 화면, 상세 시트·등록/도감/소품 화면의 위치, 실제 이동·취소·적용·새로고침이다. 전송12개 검사와 JS 문법도 확인한다. 기능 모델과 OCR 엔진 코드는 이번 외형 수정에서 바꾸지 않았고 OCR을 재실행하지 않는다. 공개 Chromium과 실제 Safari/Notion 검증은 구분한다.
