# 스마트홈 참고 이미지의 유리 질감·모듈 구성 · 2026-10-29

사용자가 회색 유리 바탕, 크기가 다른 모듈과 녹색 원형 표시가 있는 스마트홈 화면을 새 참고 이미지로 제공했다. 이 방향은 앞선 평평한 iOS 표시창 제안을 대체한다. 기준은 `06e18988`이며 사용자 디자인 승인을 의미하지 않는다.

냉장고의 양쪽 표시창에 밝은 회색 그라데이션, 흰 가장자리, 부드러운 그림자로 유리 질감을 표현한다. 글자가 흐려지지 않도록 실제 텍스트에 필터나 확대 변환을 적용하지 않는다. 화면 바탕은 불투명하게 유지해 대비를 확보한다.

- 왼쪽 `유통기한 임박`: 오늘 수치를 큰 모듈로 두고 내일·2~3일 수치를 작은 두 모듈로 나눈다. 그 아래 넓은 모듈에 재료 그림·이름·수량·기한을 배치한다.
- 오른쪽 `오늘의 추천메뉴`: 음식 그림·메뉴명, 조리시간·난이도, 녹색 원형 재료 기록률·미등록 재료를 서로 다른 모듈로 배치한다. 기록이 바뀌면 기존 이름 일치 비율로 원형 표시를 갱신한다. 아주 짧은 화면은 기존 막대 표시를 사용한다.
- 원형 수치는 **레시피에 필요한 재료 이름의 기록 비율**이다. 재고 수량의 충분함·자동 영양 분석·실시간 냉장고 센서를 뜻하지 않는다. 이름을 전부 기록해도 `이름 기록됨`·`수량 확인 필요`라고 표시한다. 참고 이미지의 조명·온도·음악 스위치를 작동하는 냉장고 기능인 것처럼 추가하지 않는다.

변경 소스는 `scene.css`의 표시창 영역, `scene.js`의 비율 CSS 변수와 짧은 안내 문구다. 기존 이름 비교 계산·기한 처리·보관 모델·저장 키·원본 그림은 유지한다. 문을 누르면 열리고 다시 누르면 닫는 조작도 그대로다. 앱·위젯의 생성 파일을 함께 갱신했다.

## 확인 범위

같은 예시 데이터·닫힌 문·고정 시각 `2026-10-28T03:00:00Z`, Asia/Seoul과 동일한 크기에서 비교했다. 앱·위젯의 649×900·390×660·320×660·320×568 총 8쌍에서 본체와 표시창의 위치·크기가 같다.

집중 검사 12개 묶음은 각각 11개 화면 조건, 8종 요리명과 메뉴 영역, 수량·기한·빈 상태·경과 양념·재료 이름 기록률 및 직접 문 조작을 통과했다. 추가 6개 앱·위젯 구성에서 0·40·100% 상태의 실제 원/막대 녹색 픽셀 수와 표시값·접근성 값을 확인했다. 모든 이름이 기록됐을 때의 수량 확인 안내, 일반 화면의 재료 행 내부 배치와 미등록 메뉴의 재료 미입력 표시도 확인했다. 픽셀 분석의 초기 Pillow 의존성 부재는 설치된 ImageMagick으로 분석 방식을 바꿔 해결했으며 제품 코드는 바꾸지 않았다.
