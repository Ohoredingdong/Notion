## 2. 세 기능을 분리한다

1. **장전 예측**: 한국 정규장 개장 전 사전 지정한 시점에 다음 정규장 개장 이후 첫 30분 수익 방향과 이벤트 위험을 기록한다. 개장 갭, 첫 30분, 당일 종가는 서로 다른 예측 대상이다. 이미 관측한 갭을 장중 예측 성과로 합치지 않는다. 미국은 해당 시장 달력과 현지 시간으로 별도 계산한다.
2. **장중 예측**: 확정된 1분봉ㆍ실시간 호가ㆍ당시 이용 가능했던 이벤트 자료를 이용하여 5분마다 향후 30분의 상승ㆍ횡보ㆍ하락 분포를 산출한다. 이는 초기 연구 주기이며 더 빠른 주기가 더 좋은 성과라는 주장은 하지 않는다. 이벤트 발생 시 새 판단을 만들되 이전 기록을 덮어쓰지 않는다.
3. **기업 투자 승인**: 시장ㆍ종목 방향 예측과 별개로 strict-green-1.0의 12개 실사, 독립 가치평가, 가격ㆍEPSㆍ기준일 정합성, 유효기간을 지킨다. 위험 알림과 연구용 예측은 실사 미완료 상태에서도 표시할 수 있지만 매수 승인으로 바꾸지 않는다.

`prediction`(미래 예측), `risk_warning`(앞으로의 위험 경고), `observation`(이미 발생한 움직임), `no_call`(판단 불가)을 구분한다. 세 방향을 모두 나열하거나 아무 추천도 하지 않은 것을 적중으로 세지 않는다. 판단 보류는 '횡보 예측'도 아니다.

## 3. 사전 예측 기록의 최소 계약

각 기록은 다음을 저장해야 한다.

- 대상 instrument/market/venue/session, 예측 originㆍissued_atㆍdelivered_at, 예측 시작ㆍ종료 시각, 타깃 정의ㆍ상하단 판정 폭.
- 실제 자료 관측 시각(event_time), 수신 시각(received_at), 외부 발표 시각(published_at), 모델이 사용할 수 있었던 시각(available_at). 원자료 생성 시각은 이들을 대신하지 못한다.
- 입력 스냅샷 해시, 회사ㆍ공시 receipt, 전망 EPS와 회계기간, 이벤트 ID, 모델ㆍ피처ㆍ정책 버전, 학습 종료일.
- 세 방향 확률 또는 명시적 no_call 사유. 확률이 있으면 합이 1이어야 하며, 보정ㆍ외부검증 상태와 표본수를 함께 저장한다. 단순 점수를 확률로 변환하지 않는다.
- 예측 당시 기준가격ㆍ실제 호가 시각, 알림 전달 후 최초 거래 가능한 매수/매도 호가, 가정한 지연ㆍ거래비용. 과거 종가로 체결했다고 가정하지 않는다.
- 예측 무효화 조건과 실제 무효화 시각. 새 판단을 냈다고 과거 예측을 삭제하지 않는다.

학습 타깃은 사전에 고정한다. 예: 30분 후 수익이 당시 정해진 작은 변동 구간보다 크면 상승, 작으면 하락, 그 사이면 횡보다. 구간은 예측 당시의 변동성 및 비용 기준으로 정하고 학습 구간에서만 조정한다. 결과를 본 뒤 구간ㆍ시점을 바꾸지 않는다. 수익성 채점은 별도의 실제 거래 가능한 호가 기준을 사용한다.

`available_at <= issued_at < target_end`가 모두 확인되어야 한다. 사용자에게 늦게 전달된 경고는 모델의 사전 연구 예측일 수는 있어도 사용자에게 유효했던 경고로 인정하지 않는다. 시각 문자열이나 해시만으로 당시 실제로 기록되었다고 증명하지 말고 서버 수신ㆍ전달 로그 및 변경 이력을 남긴다.

## 4. 입력자료 개선

### 시장과 세션

확정 종가 / 장중 잠정값 / 시간외 값을 분리한다. 한국 KRX와 NXT, 미국 정규장과 프리ㆍ애프터마켓을 혼용하지 않는다. 거래소 휴장ㆍ서머타임ㆍ분할을 반영한다. 장전 최신 완료 거래일이 없거나 가격ㆍ분봉의 기준이 어긋나면 해당 예측은 no_call이다.

미국 기준금리의 마지막 변경일, 최신 회의 결정일, 정책 시행일을 분리한다. 동결 회의가 있었는데 과거 변경을 '최근 회의 인상'으로 재사용하지 않는다. 월별 CPIㆍ실업률은 관측월ㆍ발표일ㆍ수정본을 분리하고 월간 발표주기를 무시한 단순 시간 만료를 적용하지 않는다.

### 실시간 피처

가격 수준 하나가 아니라 최근 1ㆍ5ㆍ15분 수익, 장중 고점 대비 하락, 시가ㆍ전일 종가ㆍ고정 롤링 구간 기준을 각각 유지한다. 프로그램 재시작 시 기준이 임의로 바뀌지 않도록 필요한 상태를 보존한다.

거래대금 가중 평균가격(VWAP), 같은 장중 시각의 평소 대비 거래량, 호가 스프레드ㆍ잔량 변화, 시장 대비 상대강도를 후보 피처로 검증한다. 호가 한 항목이나 매수 잔량 하나만으로 방향을 확정하지 않는다.

토스 공식 체결 스트림은 누적 거래량ㆍ매수/매도 구분이 없고 유실 가능성이 있다. 따라서 수신 체결 프레임 합산으로 정확한 누적량ㆍVWAPㆍ매수우위를 만들어서는 안 된다. 공식 REST 캔들 및 검증 가능한 누적값으로 대조하며, 지원하지 않는 값은 미확인으로 둔다. 연결 heartbeat 정상과 개별 종목의 최신 가격 수신은 다르다.

전체 코스피ㆍ코스닥의 상승종목 비율과 104개 표본의 상승종목 비율을 구분한다. 전체 시장 폭ㆍ지수 기여도에는 시점별 구성종목ㆍ가중치 또는 적법한 제공처의 시장 전체 데이터가 필요하다. 확보 전에는 '감시 표본 기준'으로만 표시한다. 외국인ㆍ기관 순매수는 구분 데이터가 실제 제공될 때만 사용한다. 개별 체결로 투자자 정체를 추정해 공식 수급처럼 표시하지 않는다.

공식 연결 한도는 계정당 2개, 연결당 채널×종목 합계 100개다. 체결과 호가를 함께 구독하면 같은 종목도 2개다. 첫 연구 대상은 검증 가능한 유동성 종목 10~20개와 시장 기준 데이터로 좁히고, 종목 수를 늘리기 전에 피처 완성도와 누락률을 확인한다. 초록 후보를 늘리려고 기존 실사를 완화하지 않는다.

## 5. 이벤트 위험과 반전 경고

공식 IRㆍDARTㆍSECㆍ중앙은행 일정에 대해 예정 시각, 확인된 실제 발표 시각, 원문, 당시 확보한 시장 예상, 실제 수치, 기간ㆍ회계기준ㆍ통화를 기록한다. 실제 실적과 예상이 같은 기준일 때만 surprise를 계산한다. 원문이 없으면 뉴스 제목을 원문 승인으로 대체하지 않는다.

발표 전에는 결과를 아는 것처럼 말하지 않고 일정에 따른 변동 위험과 방향별 조건을 제공한다. 발표 후 정보는 발표 이후 발행한 예측에만 사용한다. 좋은 실적의 절대 수준, 예상과의 차이, 이미 오른 가격, 발표 후 반응을 별개의 입력으로 둔다.

반전 연구 규칙은 '이미 -2% 하락하면 알림'에서 바꾼다. 상승분 반납ㆍVWAP 이탈ㆍ표본/전체 시장 폭 악화ㆍ주도업종 상대약화ㆍ스프레드 확대를 후보 신호로 놓고, 이후 30분의 추가 하락을 설명하는지 검증한다. 이 신호 자체도 이미 관측한 약화이며, 이후 추가 하락을 맞혔는지는 사후 별도 평가한다.

경고 상태는 관찰 → 주의 → 기존 상승 가설 무효 → 위험 해제처럼 구분한다. 단순 반복 알림은 억제하되 위험 단계 상승은 같은 방향의 30분 cooldown 때문에 막지 않는다. 안정화 조건ㆍ최소 유지시간ㆍ가격 소음 필터는 학습 구간에서 정해 과도한 경보를 함께 평가한다.

## 6. 실제 예측 모델과 검증

첫 비교 모델은 단순 기준확률ㆍ최근 추세 유지 모델ㆍ설명 가능한 로지스틱 모델이다. 추가 복잡도는 외부검증 개선이 있을 때만 허용한다. 시장별ㆍ시간대별ㆍ이벤트 유무별 결과를 나눠 보고한다. 수급 없는 모델과 수급 있는 모델을 같은 이름으로 조용히 바꿔 운용하지 않는다.

과거 데이터를 시간순으로 학습 → 조정 → 완전히 보지 않은 검증 구간으로 분리한다. 30분 타깃의 결과 구간이 검증 구간과 겹치는 학습 표본을 제외하고, 관련 종목을 같은 시각에 train/test로 나눠 누출시키지 않는다. 무작위 섞기만으로 검증하지 않는다. 당시 이용 가능한 공시ㆍ전망ㆍ지수 구성만 사용하며, 확보하지 못한 과거 호가ㆍ예상치를 현재 값으로 채우지 않는다.

동일 기록으로 여러 파라미터를 시도한 횟수와 탈락한 모델도 남긴다. 오늘 실패를 보고 오늘에 잘 맞는 규칙을 골랐다면 그날은 개발 표본이며 검증 성공 표본이 아니다. 새 규칙은 다음 독립 구간에서 재검증한다.

평가표에는 다음을 함께 표시한다.

- 예측 대상 중 실제 발행 비율, 데이터 실패ㆍ판단 보류ㆍ기한 초과 건수.
- 상승ㆍ횡보ㆍ하락별 혼동행렬, 기준모델 대비 개선, Brier/log loss 및 확률구간별 실제 발생 빈도.
- 신호 발행ㆍ전달부터 사전에 정의한 사건까지의 선행시간, 거짓 경보율, 놓친 급변, 기존 상승 신호 취소 지연.
- 알림 이후 체결 가능한 가격을 썼을 때 비용ㆍ스프레드ㆍ슬리피지 반영 성과, 불리한 변동, 비교 지수 대비 결과. 가정은 가정으로 표시한다.
- 예측 미발행을 성공으로 계산하지 않는다. 한 날 같은 시장 충격에 함께 움직인 종목 100개를 독립된 100번의 검증으로 계산하지 않는다.

확률은 보정 기록과 표본ㆍ오차범위를 함께 확인한다. 100점 중 80점은 상승확률 80%가 아니다. 수익성이 낮은 모델에 적중률 수치만 붙여 승격하지 않는다.

## 7. 승격ㆍ중단 기준

모델을 바꾸지 않은 전진 관찰에서 기준모델 대비 유의미한 개선이 있고, 기간ㆍ시장상태를 나눠도 특정 날 하나에만 의존하지 않아야 한다. 비용 후 증분성과의 불확실성은 날짜 단위 블록 재표집 등 시계열 의존성을 반영해 평가한다. 초기 승격 심사 정책은 95% 신뢰구간 하한이 0보다 큰지 등을 함께 확인하되, 이를 미래 수익보장으로 해석하지 않는다. 적은 표본이나 보정 불량이면 '미검증'을 유지한다. 관찰 일수만 채우면 자동 합격시키지 않는다.

시장 예측이 좋더라도 기업 매수 후보는 기존 12개 필수 검사, source_generated_atㆍ가격ㆍ가격 기준일ㆍ예상 EPS 일치, 유효기간, 원문ㆍfingerprint 검증을 다시 통과해야 한다. 실시간 새 가격을 과거 가격의 초록 승인에 덧씌우지 않는다. 기본실사 근거는 보존하고 새 가격 의존 검사를 새 스냅샷에 결합해 검토를 재생성하는 구조가 필요하다.

자동 주문은 이 대책의 범위 밖이다. 데이터 단절, 큰 지연, 공시ㆍEPS 변경, 성능 저하 시 추천은 정지하고 원인만 표시한다. 위험 알림까지 실사 통과를 기다리게 하지 않는다.
