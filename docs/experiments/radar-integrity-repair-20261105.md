# 투자레이더 식별·시세·검증 복구 — 2026-11-05

## 목적과 범위

기존 투자레이더의 공식 종목 식별자, 재무 출처, 완료된 정규장 가격,
확장 연구 예측과 공개 화면의 검증 경로를 복구한다. 기존 아이폰 형태 화면과
PC 한 화면 구성을 유지하고, 잘못 연결된 자료를 새 자료처럼 다시 표시하지 않는다.

## 확인된 원인과 변경

### 공식 종목명부와 재무

- 한국 6자리 종목코드의 영문을 제거하던 처리를 폐기했다. `0001A0`와
  `0009K0`는 각각 그대로 유지하며, 원본 `source_symbol`과 대조한다.
- 종목명부와 재무를 같은 수집 작업에서 검증하고 함께 게시한다. 현재 명부의
  생성시각과 재무가 참조하는 명부 생성시각이 다르면 화면에서 재무를 사용하지 않는다.
- DART 발행회사 코드와 공식 회사명·종목코드를 검증한다. SEC는 공식 종목-CIK
  대응과 companyfacts의 실제 CIK를 검증한다. 이름·코드·발행회사 식별이 검증되지
  않은 이전 자료는 원문과 해시 및 이유를 보존해 격리한다.
- 조회한 보고서의 발행회사, 결산기간, 연결 기준, 통화와 접수번호를 확인한다.
  주요계정 조회에서 받지 못한 CFO·CAPEX·FCF를 0으로 채우거나 전체 재무제표라고
  표시하지 않는다. 화면의 빈 항목은 ‘미수집·미확인’으로 표시한다.
- DART와 SEC User-Agent 설정을 분리했다. 실제 SEC 연락처가 없으면 미국
  재무 수집을 ‘미설정’으로 표시하고 가짜 연락처를 만들지 않는다.
- 실행의 수집 성공·실패·보류 수와 누적 보유량을 분리한다. 공통 수집 기한은
  18분이며, DART 명부·별칭 조회·주요계정 조회 각각의 연속 전송 실패를 3회로
  제한한다. 별칭 API 실패가 이미 공식 명부에서 확인된 회사의 계정 조회를 막지 않는다.
  제한에 도달해도 검증된 현재·이전 값은 보존하고 이번 실행의 미완료를 표시한다.
- 명시적인 `only_missing` 복구는 현재 명부에서 검증되지 않은 회사만 수집한다.
  이미 검증된 기록의 금액·확인시각과 일상 순환 cursor는 유지한다. 일상 실행은
  기존 순환 방식을 사용한다.

### 가격·차트·뉴스와 게시

- 한국·미국 거래소 달력과 장 마감 유예를 사용해 마지막으로 완료된 정규장
  종가를 고른다. 파일 생성시각을 바꿔 오래된 시세를 최신으로 보이게 하지 않는다.
- 심층 종목 자료와 그 자료를 참조하는 차트를 하나의 묶음으로 게시한다.
  병렬 차트 수집의 일시적 전송/캐시 오류에만 한 번 순차 재시도하며, 실패가
  계속되면 실제 누락으로 남긴다.
- 새 종목 자료에 맞춰 기업 이벤트를 다시 수집한 후 추천과 진입 근거를 만든다.
  뉴스 오류·부분 실패·미래 시각·시각대가 없는 시각을 정상 최신 뉴스로 인정하지 않는다.
- 감시 대상은 현재 104개 심층 기업, 지수 포함 108개 차트, 시장지표,
  예측·학습·감사·뉴스·일정 및 공식 명부·재무다. 과거 10종목 파일을 기준으로
  현재 시스템이 정상이라고 판단하지 않는다.
- 동시 게시에서는 확인한 원격 리비전으로만 합친다. 수집 입력이 바뀌면 오래된
  수집 결과의 게시를 거절하고, 진입 기록 및 평가 기록은 추가만 허용한다.
- 현재 원본과 직접 연결되는 파생 자료 15종은 실제 게시할 원본의 생성시각과
  바이트 해시를 대조한다. 더 새로 생성된 분석이어도 과거 원본에 연결되어 있으면
  게시하지 않는다. 원본과 파생 묶음을 함께 게시할 때는 그 후보 원본을 사용하며,
  push 경쟁 후 재시도할 때도 다시 대조한다.
- 과거 UI 설치기는 현재 화면을 재생성하지 않고 현재 구조와 자산을 확인한다.
  공개 배포 확인은 실제 공개 파일과 화면을 검사한다.

### AI 연구와 모의 검증

- 확장 예측은 검증된 현재 공식 식별자를 사용한다. 잘못된 식별자에 연결된 기존
  예측은 격리하고, 새 조회의 보류와 아직 유효한 이전 예측을 별도 집계한다.
- 사전 등록된 미래 실험만 평가한다. 실제 공개 확인, 실제 수신 증거, 관측된
  매수·매도 호가와 잔량 및 사전에 고정한 비용이 없으면 수익률 증거로 인정하지 않는다.
  늦게 관측한 증거를 과거 시각으로 소급하지 않는다.
- 동일 평가 집단의 후보 모델과 기준모형을 비교한다. 표본과 거래일 기준을
  충족하지 못한 모델을 승격하지 않는다. 코드 테스트 통과는 예측력·수익성 입증이 아니다.
- 공개 검증은 한 번 만든 Pages 빌드에서 예측과 모의 실험 자료를 함께 확인한다.
  추가 등록된 실험은 다음 실제 공개 확인을 기다린다.

## 계속 구분해야 하는 한계

공식 명부에 있는 회사 수, 실제 재무가 확인된 회사 수, 현재 유효한 연구 예측의
회사 수는 서로 다르다. 재무 수집 실패를 이전 누적 수로 가리거나, 코드 검증과
화면 배포 성공을 거래소 실시간 연결·모델 수익성의 증거로 표시하지 않는다.

SEC 연락처 설정, 실제 사용자의 예측 수신 증거, 거래 가능한 호가·잔량 및
고정 비용 자료는 실제 입력이 있어야 한다. 이 복구는 그러한 증거를 임의로
생성하지 않는다.
