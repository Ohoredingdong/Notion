## 사전 분석 가설·검사 방법

가설: 새로 성숙한 미국 코호트가 추가되면, 과거 6개 누락만을 대상으로 했던 '모든 가정에서 항상 횡보 진단보다 낮다'는 **제한된 36개 사건에 대한 결과**를 현재 48개 전체에 자동 확장할 수 없다. 검사는 과거 예측 방향을 그대로 유지하고, 누락 사건마다 실제 방향 `down/flat/up` 3개만 **가상으로** 부여했을 때의 정확도 차이의 정확한 가능한 구간을 구한다. 저장 원자료·결과·학습 사건에는 가상 값을 기록하지 않는다.

최초 발행의 키는 (symbol, market, mode, target.start, target.end); 동결 시각 기준 첫 예측만 선택한다. 동일 (symbol, market, mode) 그룹 내 서로 겹치는 타깃은 시간순으로 제외하고, 대상 종료 및 공개 기록이 컷오프 전에 존재하는지 확인한다. 검증된 공개 기록은 사용자 수신과 다르다. 내부 가격 산술은 외부 거래소 가격 증명이 아니다.

동일 이벤트의 기존 예측과 **사후 진단용 항상 횡보**를 비교한다. 이 진단은 사전 고정 확률 기준모델, `movement_then_direction` 후보, 투자 전략 또는 비용 후 거래성과가 아니다. 각 누락 사건의 가상 실제 방향 3개에서 `delta = 1(predicted == actual) - 1(actual == flat)`를 계산하여 기존 30개 채점 사건의 차이에 더한다.

두 방식으로 재검산했다. (A) 누락된 횡보 예측은 비교 전략과 모든 가능한 실제 방향에서 정답 차이 0, 방향 예측은 각 사건당 -1~+1이라는 독립적인 상하한 산술. (B) `Map(delta → 조합 수)` 동적계획법으로 누락 사건 18개를 차례로 3가지 방향으로 확장하여 3^18 = 387,420,489개 가상 배치의 정확한 가능 차이 구간을 계산. 두 계산의 최솟값·최댓값은 일치했다. 이는 **가상 조합의 계산 검사**이며 새 실제 시장 예측 3억 건이나 실제 데이터 확보가 아니다.
