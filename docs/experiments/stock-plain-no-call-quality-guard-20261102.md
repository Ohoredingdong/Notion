## Single pre-fixed, falsifiable hypothesis and RED
`source_failure` currently returns `None` for any `no_call` without a colon except for special rate-limit prefixes. `SafeCollector` records `result=response_received` for an untrusted quality stop such as `latest_features_missing`, `unresolved_price_discontinuity`, `intraday_source_stale` or `future_input_timestamp`. The bounded controller's `processed` gate counts such a row if `bars is not None`, so an all-quality-stopped synthetic run may publish `research_cycle_verified`, despite no valid forecast and no market-session deferral. Model exceptions with a colon are already caught by PR #89.

Create one **synthetic-only** negative test in `scripts/test_stock_timing_transaction_rollback.py` using `latest_features_missing` with dummy nonempty OHLC and an otherwise consistent minimal staged transaction: require `all_processors_failed; no_usable_source_results` and `cycle_rejected`. Include controls that session deferrals `insufficient_regular_session_time` and `target_already_started_or_delivery_window_too_short` remain a permitted process response, without treating them as actual model prediction success. Optional synthetic direct classifier checks for the other fixed quality stops use no historical market observations.

The first PR-independent-audit CI run should be intentionally RED against the untouched source. If failure is not reproduced, abandon the proposed patch. Test budget: **one RED, one minimal GREEN patch**, no model search, no hyperparameters, no reused holdout.
