# 상승·하락별 개선 · direction-specialists-1.0

목표는 실제 방향 예측력 개선이다. 모든 움직임·100% 정확도를 달성했다고 주장하지 않는다. 기존 예측·오답·실제 가격, 엄격 12개 실사, 인증된 OpenDART, 토스 연결 상태와 주문 권한은 변경하지 않는다.

## 실제 변경

기존 가격 로지스틱 모델과 점진학습 후보 외에 클래스 가중치를 적용한 선형 로지스틱·비선형 gradient boosting 후보 2개를 추가했다. 희소한 상승·하락 표본이 학습 목적에서 묻히지 않게 한다. 클래스 가중치가 확률 보정을 악화시킬 수 있으므로 별도 시간순 보정 구간과 미래 비교를 유지한다. 어느 후보도 자동으로 정확해졌다고 간주하지 않는다.

기존 입력에 최근 수익률 가속, 과거 범위 내 가격 위치, 세션 시작 이후 고점 대비 하락·저점 대비 반등·시가 대비 변화·경과시간·반전 상호작용을 추가했다. 현재 시각까지의 누적값만 사용하고 이후 봉을 읽지 않는다. 없는 호가·기관수급·이벤트 입력을 생성하지 않는다.

학습/확률보정/검증은 기존 시간순 분리와 타깃 정의를 유지한다. 보정과 과거 비교도 겹치지 않는 구간으로 측정한다. 비선형 모델의 무작위 조기종료 검증은 끄고 학습구간 밖 결과로 모델을 조정하지 않는다. 새 후보는 실제 데이터로 학습하되 shadow 상태로 발행한다. 과거 점수만 보고 현재 적용 모델을 바꾸지 않는다.

## 양방향 성적과 교체

실제 상승·하락·횡보 각각의 발생 수, 포착 수, 놓침 수, 예측 횟수, 틀린 신호 수, 포착률(recall), 정밀도(precision)를 표시한다. 표본이나 해당 방향 예측이 없으면 100%가 아니라 null/표본 없음이다. 모든 예측이 한 방향에 몰리면 명시적으로 경고한다. 전체 적중률만 높고 상승·하락을 못 잡는 모델은 합격할 수 없다.

동일 종목·기간의 같은 미래 타깃에 기존 모델·기존 점진학습 후보·새 후보 2개의 확률을 사전 동결한다. 기존 기록에 없던 후보 확률을 소급하지 않는다. 최초 예측과 오답은 보존하며, 새 후보를 평가하기 위해 최초 발행 시각을 바꾸지 않는다.

그룹별 최소 120개 비중첩 타깃·20개 관측일·실제 각 방향 10개·상승 및 하락 예측 각 10개 이상을 요구한다. 기존 모델 대비 상승과 하락 포착률 각각 3%p 이상, 균형 정확도 3%p 이상 개선을 요구하고, 각 방향 정밀도가 해당 표본의 기본 발생률보다 2%p 이상 높아야 한다. 브라이어·로그 오차 개선과 날짜 군집 진단도 함께 적용한다. 후보가 3개인 점을 반영해 진단 구간을 보수적으로 설정하되, 반복 선택·시계열 상관을 완전히 해결한 통계적 증명이라고 하지 않는다. 수치는 사전 운영 정책이지 수익 최적값이 아니다.

후보 적용 후 40개·5일 후속 블록에서 확률 오차가 악화하거나 상승·하락 포착률이 크게 악화하면 기존 모델로 원복한다. 일부 후보 수집/학습이 실패하면 원래 모델을 보존하고 실패 사실을 표시한다. 확률이 비슷하면 방향 불명확 메타데이터를 남기되 해당 원예측을 채점에서 숨기지 않는다.

## 범위와 한계

기존 12개 지수/기업의 일별·장중 모델에 연결한다. Yahoo 단일 제공처·GitHub 예약 점검이며, 토스 인증/상시 서버를 자동 연결한 것이 아니다. 모델은 실제 미래 결과가 축적되기 전 검증 완료로 표시하지 않는다. 같은 시점 여러 종목의 상관, 데이터 지연, 공급자 제한은 남아 있다. 실거래 체결·비용 후 수익률은 별도 검증 대상이다.

새 단위 검사 24개는 합성 테스트 입력으로 미래 누수·한 방향 몰림·희소 표본·거짓 신호·양방향 교체·모델 성적 오인용·원기록 보존을 검증한다. 합성 자료는 운영 시세나 예측에 사용하지 않는다. 실제 생성 JSON의 1280/390 화면과 공개 JSON·JavaScript 해시를 별도 확인한다.
