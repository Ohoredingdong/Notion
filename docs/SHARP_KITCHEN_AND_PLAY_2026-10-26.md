사용자가 냉장고와 디스플레이의 흐린 품질 개선, 열린 문을 다시 클릭해 닫기, 아래 개폐 버튼 제거와 앞서 제안한 기능의 추가 수정을 요청했다. `design/centered-kitchen`의 `da996f30`에서 분리한 `feat/kitchen-play-and-sharp-displays`에서 독립 앱·위젯 시안을 확장했다. 기존 서비스·저장 키·배포 URL은 변경하지 않는다.

## 냉장고와 디스플레이

이전 디스플레이는 방의 `transform:scale`과 문 원근·단계 필터 안에서 그려져 글자까지 함께 합성·축소됐다. 새 화면은 문에 맞춰 **별도의 변형 없는 HTML 레이어**를 놓고, 실제 화면 픽셀에 맞춰 위치와 크기를 반올림한다. 이름 11px 이상, 충분한 대비와 선명한 테두리를 사용한다. 디스플레이는 열린 문에서 숨기고 문이 닫히는 회전이 끝난 뒤 표시해 화면이 먼저 떠 보이지 않게 한다. 동작 줄이기 설정에서는 즉시 반영한다. 중앙 구도와 배경·바닥 정합은 유지한다.

냉장고 아틀라스의 WebP 품질은 82→94로 높이고, 다른 자산의 웹 인코딩을 조정해 전달 크기를 유지했다. 원본 PNG는 보존한다. 배경은 품질76, 식재료·양념은82, 소품 아틀라스는 원본 좌표를 유지해643×612, 새 마그넷은627×627로 인코딩한다. 디스플레이 글씨는 그림으로 압축하지 않는다. 이 작업은 냉장고 원본의 해상도를 새로 생성하거나 모든 소재가 원본과 픽셀 단위로 같다는 주장이 아니다.

네 문은 닫혀 있을 때 클릭/탭해 열고 **열린 문을 다시 클릭/탭해 닫는다**. 열린 문도 키보드 접근이 가능하다. 아래 네 개 개폐 버튼은 DOM에서 제거했다. 재료 편집·드래그·닫힌 칸 입력 차단을 유지한다.

식사 취소 복구는 현재 세션의 가장 최근 취소 한 건을 복구한다. 새로운 식사를 기록하거나 다시 열면 해당 취소 복구 버퍼는 초기화된다. 영양은 자동 추정하지 않으며 식사 기록으로 기존 재고 수량을 자동 차감하지 않는다. 사진 인식·실제 식비·월간 앨범·영양제 연동은 후속이다.

## 저장 경계와 실패 처리

새 키는 **`miniature-kitchen-preview-v1` 하나**다. 원본 앱의 `use-me-first-state-v5`, `use-me-first-life-v1`, 위치·동기화 등의 키를 읽거나 쓰지 않는다. 이름·수량·날짜가 기본 예시와 같아도 저장된 시안 기록을 임의로 초기화하거나 기한을 갱신하지 않는다.

같은 출처에서 앱·위젯을 새로 열면 같은 시안 저장을 읽는다. 동시에 열린 다른 창의 수정이 감지되면 이전 창의 저장을 멈춰 새 기록 덮어쓰기를 막는다. 이는 실시간 동기화·기기 간 동기화가 아니다. 기존창은 새로 열거나 백업한다.

저장소가 막힌 opaque iframe·권한 오류·용량 오류에서는 임시 세션이라고 표시하고 JSON 보관을 제공한다. 손상된 기존 시안 저장은 원본을 유지하고 새 저장을 중단한다. 잘못된 백업은 현재 상태를 교체하지 않는다. 정상 백업은 검증한 뒤 시안 상태만 교체한다. 충돌·읽기 오류가 있으면 임시 상태로만 복원하며 원본 저장은 유지한다.
