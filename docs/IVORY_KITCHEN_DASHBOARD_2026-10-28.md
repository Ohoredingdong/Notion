# 화이트 냉장고용 정보형 디스플레이 · 2026-10-28

사용자는 참고 사진의 검정색을 복사하는 대신 흰 냉장고에 어울리는 배경과 더 풍부한 내부 구성을 원한다고 정정했다. 기준은 `b0954932`이며, 앞선 [검정 표시창](GLASS_KITCHEN_DISPLAYS_2026-10-28.md)은 미채택 시안이다.

## 밝은 표면과 정보 구성

- 아이보리 화면·실버 가장자리·옅은 세이지색 포인트를 사용한다. 냉장고 본체와 배경 그림은 바꾸지 않는다.
- **유통기한 임박:** 오늘·내일·2~3일 이내 개수 카드, 재료/양념 이름·수량·날짜, 전체 또는 경과 개수, 기한 분포 막대를 표시한다. 개수는 재료 관리 기록의 **건수**이며 동일 이름의 여러 용기를 서로 다른 종류로 부르지 않는다. 기한이 지난 항목은 붉은 표시와 문구로 구분한다.
- **오늘의 추천메뉴:** 기존 요리 그림·이름에 조리시간·난이도, 재료 기록 비율과 막대, 미등록 재료를 추가한다. 예시 계란 볶음밥은 계란·간장 기록이 있어 2/5로 표시된다.
- 재료 비율은 기존 레시피의 신선 재료·양념·상비 재료 이름 중 기록에 있는 **종류 수**다. 같은 이름의 여러 용기는 중복 집계하지 않고, `밥/즉석밥`처럼 레시피에 명시된 대체 이름을 인식한다. 기한이 지난 기록은 제외한다. 기한이 없는 기록은 이름 기록으로만 계산하며 수량·영양·조리 가능 여부를 검증했다는 의미가 아니다. 화면의 설명과 접근성 이름에 `이름 기준, 수량 미검증`을 둔다.
- 레시피 추천 순위를 자동 계산하는 기능, 재고 차감, 가격·칼로리 추정을 새로 구현한 것으로 보고하지 않는다.

## 크기별 구성

넓은 표시창은 세 개의 기한 카드와 미등록 재료까지 표시한다. 작은 표시창은 이름·수량·사진·시간·두 막대를 우선하고, 아주 짧은 화면은 사진을 생략한다. 제목 두 개는 축약하지 않는다. 패널 높이를 조금 늘리고 작은 화면에서는 위쪽으로 배치해 냉장 글씨·손잡이와의 여백을 유지한다. 본체 크기와 중앙 배치, 직접 문 개폐, 기존 저장 키와 형식은 그대로다.
