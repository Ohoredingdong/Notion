# 실제 결과 채점 → 학습 → 후보 검증 · delayed-forward-learning-1.0

100%에 가까운 적중률을 구현 완료했다고 주장하지 않는다. 구현 대상은 틀린 예측을 숨기지 않는 사전 검증, 지연 정답에 대한 점진적 학습, 후보 모델의 비교·원복이다. 모델 출력·테스트 성공·실제 예측력·실거래 수익은 별개다. OpenDART, strict-green-1.0, 문서 승인, 가격 원자료, 토스 인증 설정과 주문 권한은 변경하지 않는다.

## 작동 순서

1. 이전에 발행한 예측·공개 확인 기록과 실제 미래 구간 OHLC를 대조한다. 구간이 끝나지 않았거나 시세가 빠졌으면 적중으로 세지 않는다. 장중 타깃은 정확한 6개 5분봉이 있어야 채점한다.
2. 당시 발행한 확률·방향·판정 폭을 고정한 채 채점한다. 현재 모델로 과거를 다시 예측해 성적을 수정하지 않는다.
3. 타깃 시작 전에 공개 확인된, 중복과 시간 겹침을 제거한 결과만 학습 후보에 반영한다. 같은 결과를 재실행 때마다 반복 학습하지 않는다.
4. 학습한 후보와 기존 모델은 다음 동일 타깃에 대해 나란히 확률을 저장한다. 후보의 성능은 그 뒤 확인되는 결과로 비교한다.
5. 사전에 정한 비교 문턱이 충족될 때만 연구용 화면의 적용 모델을 변경한다. 부족하면 기존 모델을 유지한다. 매수 승인이나 주문은 별도이며 자동 활성화하지 않는다.

## 학습 방식과 한계

기존 가격 모델을 기준으로 정규화된 선형 softmax 잔차를 작은 학습률로 갱신한다. 입력은 원 예측 당시 저장한 가격 피처이며 고정 스케일·클리핑을 사용한다. 확률을 100%로 보이게 조작하거나 새 기관 수급·이벤트 정보가 있는 것처럼 표시하지 않는다. 모델 상태는 JSON으로 저장하고 이전 상태 해시가 맞을 때만 게시해 동시 실행이 학습 결과를 덮어쓰지 못하게 한다.

학습 후보는 작은 표본에 과적합할 수 있다. 후보 확률은 아직 미래 검증이 끝나지 않은 연구용 추정이며, 이 학습 방법이 기존 모델보다 낫다는 보장은 없다. 기존 과거 검증과 새 미래 성적을 구분한다.

## 집계 기준

동일 종목·시장·기간·타깃 시작/종료의 첫 발행만 대표 예측으로 사용한다. 모델 버전을 바꾸어 같은 사건을 여러 번 맞힌 것으로 세지 않는다. 시간 구간이 겹치면 시간순 고정 규칙으로 대표 구간을 선정하며 결과를 보고 고르지 않는다. 종목 간 상관까지 사라지는 것은 아니다.

지표: 정답/평가 표본, 방향별 재현율, 균형 정확도, 혼동행렬, 브라이어·로그 오차, 확률 보정 구간, 70% 이상 확신한 사례의 적중과 그 비중, 고정된 실행 시도 대비 보류율. 예약 작업이 실제로 실행되지 않은 시간까지 완전한 전체 기회 표본이라고 주장하지 않는다.

새 기록은 사전 학습구간 빈도 기준모델의 확률도 함께 고정해 이후 같은 사건끼리 비교한다. 기존 기록에 없던 기준값을 결과를 보고 소급 생성하지 않는다. 공개 웹 응답 확인은 사람의 푸시 수신을 뜻하지 않는다.

Wilson 95% 구간은 독립 표본 가정의 참고치다. 같은 날 시장의 종목·구간 상관을 고려해 날짜 단위 재표본 진단도 별도로 제공한다. 이 진단은 반복 모델 선택과 모든 시계열 상관을 해결한 통계적 증명이 아니다.

## 연구 후보 교체·원복 정책

최소 120개 겹치지 않는 같은 타깃, 20개 관측일, 각 방향 최소 10개를 기본 요건으로 한다. 미리 정한 블록 단위에서 후보의 브라이어 개선 0.01 초과, 로그 오차 개선 0.005 초과, 방향 정확도 개선과 날짜 재표본 하한 양수를 확인한다. 작은 변경마다 같은 검증 구간을 반복 탐색하지 않는다.

후보 적용 후 최소 40개 타깃·5개 관측일의 후속 블록에서 기존 모델보다 확률 오차가 악화되는 기준을 충족하면 기존 모델로 원복한다. 이 수치는 운용 정책이며 이론적으로 최적인 값이나 수익 보장이 아니다. 기준모델도 실패할 수 있다.

## 실제 실행 속도

현재는 토스 실시간 연결이 아닌 Yahoo 단일 제공처와 GitHub Actions다. 설정된 한국·미국 장 시간대에 약 10분 간격으로 예약하고 한국 장전 점검을 추가했다. Actions와 제공처가 지연될 수 있으므로 실시간 입증으로 표시하지 않는다. 결과는 미래 타깃이 끝나고 가격이 도착한 뒤에만 알 수 있다.

## 파일과 검수

stock-forecast-learning.json: 공개 성적표. stock-forecast-learning-state.json: 학습 상태. stock-forecast-attempts.jsonl: 예측/보류 시도. stock-forecast-learning-events.jsonl: 실제 결과 학습·모델 변경 이력. 기존 forecast ledger/outcomes/deliveries는 보존한다.

새 단위 검사 35개와 기존 예측 검사를 함께 실행한다. 실제 JSON을 이용한 데스크톱·모바일 검사 및 공개 JSON/JavaScript 해시 대조 후 배포 여부를 판정한다. 합성 가격은 테스트 파일에서만 사용한다.
