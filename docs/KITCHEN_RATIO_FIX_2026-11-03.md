# 사진·부엌·화면 프레임의 비율 수정

사용자가 직전 결과의 비율을 다시 지적했다. 직전 실제 화면과 저장된 시안의 같은 폭 비교에서 레시피 사진은 가로가 약 2.05배, 내 부엌 배경은 약 1.90배 늘어난 것을 확인했다. 화면마다 홈/다른 메뉴/입력창의 폭과 높이도 달랐다. 이전 기능 통과는 비율 검증을 대신하지 않는다.

- 레시피 사진의 `preserveAspectRatio="none"`를 제거했다. 메인 카드 3.8:1, 보조 카드 2.55:1 영역 안에서 원본을 균일하게 확대·잘라 표시한다. 사진 아래 정보 영역은 약 89px이며 제목/수치가 사진에 눌리지 않게 한다.
- 내 부엌 배경을 1402:1122로 유지하고, 위쪽을 목표/균형 카드 뒤로 가린다. 냉장고는 1007:1300을 유지한다. 배경을 납작하게 줄여 빈틈을 채우지 않는다. 꾸미기 편집의 닫힌 냉장고도 같은 원본 비율이다.
- 모든 메뉴와 집중 입력창이 같은 프레임 폭을 공유한다. 정보 화면과 집중 입력창의 높이도 같다. 냉장고 홈은 시안에서 측정한 거의 정사각형인 1.01 높이/너비를 따르며, 320px에서는 44px 조작을 위해 최소 360px 높이를 둔다. 긴 뷰포트에서는 프레임을 가운데 놓는다. 기본 dialog 최대 너비 때문에 390px에서 입력창만 354px로 줄던 문제를 제거했다.
- 사진 두 장은 0.70 세로 비율을 유지한다. 요리 상세 사진은 2.60:1이며 18px/16px 여백 충돌과 90/120/190px의 조건별 고정 높이를 제거했다. 넓은 짧은 화면에서는 재료와 순서를 두 열로 배치한다.
- 열린 냉장고 몸체의 약 0.85 가로/세로 비율은 저장된 시안과 약 1% 이내여서 유지했다. 같은 비율로 표시 크기를 조정하고, 상단 요약 폭과 높이 및 본체의 위쪽 위치를 맞췄다.

앱·위젯 공유 소스와 기존 저장 키/v1·재료 좌표·기록·거래·보상을 보존한다. 새 이미지나 예시 수치를 기본 사용자 데이터에 추가하지 않았다. 원본 시안은 프레임별 크기가 다른 설계 이미지이므로, 실행 화면은 하나의 앱 프레임 안에서 원본 사진과 물체 비율을 보존하는 기준으로 검토한다.

같은 예시 데이터·뷰포트의 수정 전후 이미지, 실제 요소 크기와 최종 공개 실행 증거는 `docs/kitchen-ratio/`에 기록한다. Chromium의 모바일 크기 검사이며 실기기·Safari·Notion·OCR 재실행을 뜻하지 않는다.
