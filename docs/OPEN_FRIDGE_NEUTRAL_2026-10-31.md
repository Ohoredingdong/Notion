# 열린 냉장고 · 중립색 UI와 생활 기록 연결

기준: 2026-10-31 Asia/Seoul. 작업 브랜치 `feat/open-fridge-neutral-ui`. 변경 전 기준 `cd056d46`.

사용자가 선택한 **04 열린 냉장고**, 아이보리 벽·린넨 햇살·밝은 우드 바닥, 파랑 강조 제거를 실제 앱·위젯 검토 화면에 적용했다. 이전의 회색 유리/세이지/진녹색 시안보다 이 결정이 우선한다. 구현 결과의 최종 시각 검수와 main 배포 승인은 별도다.

## 구현 위치와 데이터 경계

- 공통 소스: `designs/miniature-kitchen/scene.html`, `scene.js`, `neutral.css`, `play-model.js`, `play-ui.js`, `workflow-model.js`, `workflows.js`.
- 생성 파일: `previews/miniature-kitchen-{app,widget,board}.html`, `previews/mobile/{app,widget}.html`. 앱·위젯은 같은 모델과 기능을 사용한다.
- 원래 `use-me-first.html`·`use-me-first-widget.html`, 운영 JS/CSS, 원래 저장 키와 배포 URL은 변경하지 않았다. 이 화면으로 운영 데이터가 자동 이전되지는 않는다.
- 기존 시안 키 **`miniature-kitchen-preview-v1`**, envelope **version 1**을 유지한다. 선택적인 `workflow` 필드만 추가했다. 이전 world/play만 있는 백업도 읽으며, 과거 기한·좌표·수량을 갱신하지 않는다. 알 수 없는 envelope 필드는 보존한다.
- 일반 출처에서 실행하면 이 기기의 시안 기록을 저장한다. 공개 HTMLPreview 링크는 `sandbox="allow-scripts"`인 별도 출처 프레임에서 실행하므로 **임시 세션**이다. 화면에 실제 저장 상태와 JSON 백업을 제공한다. 기기 간 동기화는 연결 전이다.
- 가져오기는 형식 검사→차이 미리보기→확정 순서다. 저장 가능 환경에서는 교체 전 원문을 같은 키의 `-recovery`에 보존한다. 잘못된 기존 원본·다른 탭과의 충돌은 저장을 중단하며 운영 기록을 덮어쓰지 않는다.

## 거래 규칙

`workflow-model.js`는 저장·네트워크 없이 수량과 차감 영수증을 계산한다. `play-ui.js`는 world/play/workflow의 복제본을 함께 검증한 뒤 한 번 반영한다. 부족 수량·잘못된 날짜·호환되지 않는 단위가 있으면 전부 반영하지 않는다. 취소는 그 식사에서 쓴 수량만 더하므로 다른 식사의 정상 차감을 유지한다. 직접 재고를 수정한 뒤에는 `manualRevision` 차이를 검사해 과거 수량으로 덮어쓰지 않는다. 식사 ID는 새로 생성하며 복구는 원래 ID를 유지한다. 같은 요리를 취소·복구·재기록해 꾸밈권을 반복 지급하지 않는다.

## 시각·실행 검증

검토 증거와 공개 링크 확인 결과는 이 문서 아래에 기록한다. Chromium 화면 크기 검사를 실기기/Safari/Notion 검증으로 표현하지 않는다. 이전의 어두운 LCD 픽셀·고정 1536×1024/첫 화면 높이 계약을 검사하던 구형 시안 전용 브라우저 스크립트는 보존하되 이번 디자인의 통과 증거로 사용하지 않는다. 새 검사는 저장·거래·기한 보존·문 첫 프레임·실제 조작을 검증한다.

```bash
source /workspace/.notion-cloud/activate.sh
python scripts/build_miniature_kitchen_preview.py --compact
python scripts/build_kitchen_mobile_preview.py
python scripts/test_open_fridge_neutral_browser.py --root previews --output /tmp/open-fridge-neutral-browser
node --test tests/*.test.cjs
PYTHONPATH="$PWD:$PWD/scripts" python -m unittest discover -s scripts -p 'test_*.py'
```

원본 PNG 자산은 보관하고 공개 미리보기에는 인코딩·크기만 줄여 포함한다. 원본 자산을 압축본으로 덮어쓰지 않는다. 작은 자산 변경 후에도 실제 생성 HTML을 다시 검사한다.
