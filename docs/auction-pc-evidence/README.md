# 경매노트 PC 웹 화면 비율 수정

사용자가 지적한 대상은 모바일이 아닌 **PC 웹 경매노트**입니다. 이 비교는 같은 연습 물건과 브라우저에서 확인한 PC 화면입니다.

| PC 해상도 | 수정 전 | 수정 후 |
|---|---|---|
| 1366×768 | [전](1366-before.png) | [후](1366-after.png) |
| 1920×1080 | [전](1920-before.png) | [후](1920-after.png) |

확인한 문제는 상단 요약 3개와 하단 상세 3개의 열 너비가 서로 달랐고, 큰 모니터에서 하단 카드가 약 635px로 늘어나 검토 단계 한 행이 약 139px까지 벌어지는 것이었습니다. 기존 기능 검사는 통과했지만 새 PC 비율 검사는 이 상태를 실패로 재현했습니다.

PC에만 적용하는 CSS로 상·하단 열을 같은 3열·12px 간격에 맞추고 하단 카드 최대 높이를 360px로 제한했습니다. 좁고 낮은 PC 화면은 남은 공간에 맞춰 줄어들며 페이지 전체 스크롤이 생기지 않습니다. 카드 제목 기준선과 큰 화면의 숫자·본문 크기도 조정했습니다. 모바일 배치는 바꾸지 않았습니다.

실제 1280×720, 1366×768, 1440×900, 1920×1080에서 캡처·비교했습니다. 회귀 검사에 열 경계·제목 위치·과도한 카드 높이·읽기 간격을 추가했고, 기존 경매 브라우저 9개 시나리오와 모바일·저장 제한 iframe 검사를 유지했습니다. 중간에 확인한 제목 기준선 약 1.6px 차이는 헤더 정렬을 조정한 뒤 재검증했습니다.

금융 계산·기록·데이터는 바꾸지 않았습니다. 작업 브랜치 수정이며 공개 사이트 배포 완료를 의미하지 않습니다.
