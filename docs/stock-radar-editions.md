# 투자 레이더의 두 버전 / 고정 링크 계약

사용자 요청: “개인연구용이랑 공개판매용 두개만들어서 링크 2개로 줘 항상”.

투자 레이더의 후속 수정·완료·링크 안내에서는 아래 두 링크와 각 상태를 항상 함께 표시한다. 원본 주소를 폐기하지 않는다. 미배포 링크를 만들어 안내하거나, 연구판을 판매 가능한 제품으로 표현하지 않는다.

| 버전 | 고정 주소 | 실제 상태 |
|---|---|---|
| 개인 연구용 | https://ohoredingdong.github.io/Notion/stock-radar-research.html | 기존 stock-value-radar.html을 그대로 불러오는 연구용 진입 화면. 접근제어가 없어 비공개 웹사이트가 아님. |
| 공개·판매용 | https://ohoredingdong.github.io/Notion/radar-public/ | 가상 자료와 직접 입력 도구의 프로젝트 시연판. 실시간 시세·AI 매매신호·결제·유료 판매는 미개시. |

기계 판독 계약은 `stock-radar-editions.json`이다.

## 데이터·배포 경계

- 개인 연구용은 원래 화면, 연구 원장, 예측·오답, 수집기, 기존 검증 기준과 별도 예약을 변경하지 않는다. 이 변경은 연구 자료에 상업적 재배포 권한을 부여하거나 기존 공개 파일을 비공개로 전환하지 않는다.
- 개인 연구용이라는 이름이나 robots noindex는 접근통제가 아니다. 비공개화에는 별도 인증·비공개 호스팅·저장소 전환이 필요하다. 프런트엔드 암호창이나 숨긴 URL로 이를 대신하지 않는다.
- 공개판의 런타임은 `radar-public/` 안에서만 작성한다. 기존 연구 JS, 시세 JSON, 연구 성적표, 외부 차트, 뉴스 본문, 외부 글꼴을 복사하거나 요청하지 않는다.
- 공개판의 모든 기본 수치는 직접 작성한 가상 예시이며 실제 회사·거래일·수익률·예측 성능으로 제시하지 않는다. 실제 지수 값은 미연결 상태로 둔다.
- 공개판 CSP는 `connect-src 'none'`, `frame-src 'none'`이다. 출처 링크를 이용자가 누르는 것은 별도 원본 방문이며 데이터 복제·자동조회와 구분한다.
- 공개판은 연구판 링크를 방문자에게 제공하지 않는다. 개인 연구용 진입 화면에서만 공개판과 기존 화면 링크를 제공한다.
- 공개판 localStorage 키는 `radar-public-demo:journal:v1`뿐이다. 기존 연구용 키를 읽거나 재사용하지 않는다. 메모는 로그인·서버 동기화·암호화 저장이 아니며 공용 기기 접근에 주의한다.
- 실제 판매용 배포에는 `radar-public/`의 허용 파일만 사용한다. 저장소 루트 전체를 새 상업 사이트에 배포하지 않는다. 같은 기존 GitHub Pages 호스트에 다른 연구파일이 존재한다는 사실을 숨기지 않는다.
- `radar-public/netlify.toml`은 이 디렉터리를 별도 사이트로 배포하기 위한 설정일 뿐, 실제 Netlify 연결·배포 성공의 증거가 아니다. 유료 계정·도메인·시세 계약을 임의 구매하지 않는다.

## 승인·출시 경계

현재 `commercial_ready=false`. 프로젝트 시연판을 공개한 것과 유료 서비스 출시 허가를 혼동하지 않는다. 실제 시세를 표시할 때는 공급처의 외부표시·저장·분석·결과 제공 범위를 확인하고, 실제 계약·허용 범위의 근거 없이는 켜지 않는다. 투자조언/추천·회원·결제·개인정보 처리의 서비스 범위도 별도로 검토해야 한다.

확인한 공식 기준(2026-11-10):
- Yahoo Finance 제공처 안내: https://help.yahoo.com/kb/SLN2310.html — 데이터 재배포 권한 미확보.
- GitHub Pages 제한: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits — 현재 공개판은 프로젝트 시연이며 상업 SaaS 운영 아님.
- Netlify 무료 플랜 안내: https://www.netlify.com/blog/introducing-netlify-free-plan/ — 상업 프로젝트 배포 경로가 있지만 사용량·계정 연결 및 실제 운영 증거는 별도 확인.

## 점검

`python scripts/test_radar_editions.py`로 허용 파일, 연구 데이터 비혼입, 출처 링크, CSP와 버전 계약을 검사한다. `python scripts/test_radar_editions_browser.py`는 로컬 서버에서 화면·계산·저장·충돌·네트워크 경계를 확인한다. 연구판 변경은 별도 기존 회귀검사를 유지한다. 공개 배포 완료는 실제 HTTP 파일 해시와 두 진입 화면을 확인한 뒤에만 보고한다.
