# 문 열림 전 식재료 선노출·문 표면 글씨 제거 · 2026-10-29

사용자가 물품이 문보다 먼저 보인 뒤 정상 동작하는 현상을 보고하고 문 표면의 ‘냉장·냉동’ 글씨 제거를 요청했다. 기준은 `39edc1b8`이며 실행 UI는 `6f20477e`와 같다.

## 재현과 수정

문이 논리적으로 열리는 즉시 재료 구획은 표시되는데, `preserve-3d`인 문 그룹의 그리기 순서가 명시되지 않아 재료가 그 앞에 그려졌다. 실제 열림 전환을 0도에서 멈추자 브로콜리가 닫힌 문 위에 보이고 입력 대상도 재료로 잡혔다.

내부 그룹을 아래, 문 그룹을 위에 두는 순서를 명시했다. 식재료를 임의 시간 동안 숨기지 않고 실제 문이 회전해 드러낸 부분에서만 보이도록 가린다. 열린 구획의 재료 선택·드래그와 겹침, 문에 붙은 표시창과 닫힘 복원은 유지한다.

문 표면 글씨를 만드는 `door-label`과 관련 CSS를 제거했다. 네 문의 접근성 이름과 재료 편집의 냉장/냉동 구획 선택명은 유지한다. 본체·배경·문/LCD의 좌표·크기, 그림 원본과 저장 키·형식·수량·기한 계산은 바꾸지 않는다.
