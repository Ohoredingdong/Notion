# after-v6 시각 검토

실제 네 HTML의 8개 프로필·4개 화면 경로에서 200단언이 통과했다. 별도 앱/위젯 390px 내비게이션 40단언도 통과했으며, 탭 문자는 글자마다 9개의 실제 hit point로 확인했다. 전후 8쌍의 초기 원문·envelope·shell/tray가 동일하고, 런타임 소스 59개가 동결 해시와 일치한다.

직접 연 PNG 12장의 범위에서 초기 열량 노출, 개인 섭취 인분, 상단 목표 설정, 앱 390px 탭 가림과 위젯 제목 중복이 모두 수정된 것을 확인했다. 남은 실제 문제는 없으며 수동 검토 판정은 통과다. 입력·이미지 해시와 직접 검토 목록은 manual-review.json에 보존한다.

이는 사용자 디자인 승인이나 실제 Notion·Safari·실기기·공개 HTMLPreview 실행·운영 배포 확인을 뜻하지 않는다.
