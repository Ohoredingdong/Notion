# 식생활·요리 도감·꾸미기 게임 제안

2026-10-26 사용자는 꾸미기와 성장을 함께 원하며, **캐릭터를 키우는 방식이 아니라 영양 섭취 게이지와 레시피 도감 등**을 원한다고 답했다. 아이디어를 먼저 제안해 달라는 요청이다. 아래 규칙·목표 수치·보상은 제안이며 확정 또는 구현 완료가 아니다. 캐릭터·허브 성장이나 기존에 거절된 생활 대시보드를 다시 넣지 않는다. 커뮤니티·수익화는 보류한다.

## 현재와 목표

현재 독립 시안에는 재료/양념의 예시 수량·기한 수정, 네 문, 드래그와 소품 배치만 있다. 실제 식사·섭취 영양소·도감·목표·보상·성장 기록은 연결하지 않았다. 모든 시안 값은 메모리의 예시이며 새로고침하면 초기화된다.

성장 대상은 **내 식생활 기록, 만들어 본 요리의 도감, 내가 꾸민 부엌**이다. 매일 새로 확인하는 영양 목표와 오래 쌓이는 도감·꾸밈 컬렉션을 구분한다.

## 제안

| 요소 | 작동 방식 | 눈에 보이는 변화 |
| --- | --- | --- |
| 하루 영양 게이지 | 식사 기록의 인분·실제 섭취량으로 탄수화물/단백질/지방·식이섬유·수분 등을 합산한다. 사용자가 선택한 목표 범위에 도달하면 완료 표시 | 냉장고 디스플레이나 별도 식사 화면에 색이 구분된 게이지. 상세 화면에는 값·단위·출처·미상 항목 |
| 레시피 도감 | 새로운 요리를 실제 식사 기록에 넣으면 요리 카드를 채운다. 만든 횟수, 사진, 나만의 팁과 재료 바꾼 버전을 남긴다 | 빈 카드 → 첫 요리 카드 → 사진과 내 버전이 쌓이는 도감. 한식/아침/도시락/간편식 등 컬렉션 |
| 선택하는 요리 미션 | ‘새 반찬 2개’, ‘두부로 서로 다른 요리’, ‘보유 재료로 예산 안의 세 끼’ 등에서 1~2개를 고른다 | 선택한 목표의 진행률과 완료 순간 표시. 기록·요리 다양성·계획 실천으로 보상 |
| 부엌 꾸미기 보상 | 예: 첫 요리 기록으로 마그넷 선택, 도감 다섯 개로 소품 선택. 보상은 제안된 선택지에서 직접 고르고 배치 | 냉장고 자석·액자·선반·그릇 등 실제 공간에 적용되는 수집품. 기본 재료 관리 기능은 계속 이용 가능 |
| 월간 부엌 앨범 | 그달의 새 요리, 식사·식비·영양 기록과 채워진 도감을 한곳에 모은다 | 요리 사진 달력, 식비 비교, 영양 비율, 이번 달 새로 생긴 요리책/소품을 보는 앨범 |

첫 구현 조합은 **영양 목표 게이지 + 요리 도감 + 선택하는 꾸미기 보상**을 추천한다. 하루 식사 기록 → 영양 목표 진행 → 새 요리 등록 → 보상 선택 → 부엌 적용이 하나의 흐름이 된다. 미션·월간 앨범은 이 기록을 재사용해 확장한다.

## 데이터와 동작의 조건

- 게이지는 목표 범위로 표시한다. 보상은 기록·요리 경험·다양성·선택한 계획의 실천에 연결한다. 영양소 수치를 무한히 올리는 방식으로 설계하지 않는다.
- 기존 고정 kcal 예시를 실제 섭취량으로 취급하지 않는다. 레시피/식품의 영양 출처·기준량·인분과 실제 먹은 양이 필요하다. 누락은 ‘미상’, 추정은 ‘추정’으로 표시한다.
- 개인 목표는 사용자가 설정·변경할 수 있게 한다. 근거 없이 건강 상태나 의학적 점수를 산출하지 않는다.
- 식사 취소·수정 시 영양 합계를 다시 계산한다. 같은 식사를 중복 기록해 도감 보상만 반복 획득하지 않게 할 규칙도 필요하다. 보상 회수·기록 삭제 정책은 별도 확정한다.
- 레시피 찾기와 재료 관리의 실용 기능은 유지한다. 도감은 실제 만들어 본 기록과 사진·변형 레시피가 쌓이는 수집 경험으로 설계한다.
- 실제 저장·동기화·기존 재고와 식사 기록의 연결이 먼저 필요하다. 현재 시안에 이 기능들이 존재한다고 보고하지 않는다.
