This would falsely imply that a usable research cycle ran, although it would not prove any forecast edge or change a stored prediction.

Provide a minimal, audit-consistent stage; assert the run rejects, retains existing original bytes and does not publish verified status. Legitimate market-session no-call with successfully processed history must continue passing.

Do not automatically retry structural errors. Preserve recorded raw attempts, forecast probabilities, past outcomes, learning weights, approvals and the four-candidate catalogue.
