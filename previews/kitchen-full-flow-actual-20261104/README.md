# 실제 구현 화면 갤러리

검토용 예시 데이터를 사용한 실제 구현 화면 24장입니다. PNG는 입력 캡처 원본과 바이트가 같습니다. 화면 버튼은 갤러리 캡처 사이를 이동하며 실제 재고·식사·지출·꾸밈권을 변경하지 않습니다.

`index.html`을 일반 HTTP(S) 서버에서 열면 됩니다. 기본 PNG 경로는 상대경로 `images/A1.png` 형식입니다. 모바일은 한 화면 선택, 데스크톱은 3×2 격자이며 화면을 눌러 크게 볼 수 있습니다.

A4 등 사진 검수에 표시된 인식값은 캡처의 검토용 예시이며 OCR 정확도 실행 증거와 구분합니다. 원래 QA 범위와 원본 해시는 `manifest.json`을 참고하세요.

공개 HTMLPreview에서도 같은 PNG를 열도록 이미지 경로는 `295b2fa0d248e019ce90b8440fb0b0edbd874b1e`의 원본 파일에 고정했다. 갤러리 HTML과 PNG의 버전 차이는 경로 고정만이며 이미지 바이트는 같다.
