# 한끼의 부엌 새 디자인 제안

후속: 11월 9일 사용자가 이 시안의 실제 적용을 요청했다. 현재 실행물과 검증 범위는 [위젯 적용 기록](../../docs/KITCHEN_REFRESH_APPLIED_2026-11-09.md)을 따른다. 아래는 11월 8일 제안 당시의 상태다.

2026-11-08 “디자인부터 다시해봐” 요청에 만든 **이미지 시안**이다. 실제 구현·브라우저 캡처·사용자 최종 승인·운영 배포와 구분한다. 기존 위젯 코드와 사용자 기록은 변경하지 않았다.

- [냉장고 홈](01-home.png): 큰 빈 영양제 판을 짧은 행으로 정리하고 부엌·음식의 표현과 정보 위계를 통일한다.
- [네 탭 디자인 보드](02-four-tabs.png): 냉장고·8개 비교 레시피·음식 달력/식비·부엌 꾸미기를 같은 크기와 색으로 구성한다.
- [디자인 기준과 보존할 동작](DESIGN_SPEC.md)
- [이미지 출처·해시·검토 범위](manifest.json)

이미지의 제품·수치·식사·금액은 시안용 예시다. 제품 기본값이나 실제 사용자 결과로 넣지 않는다. 모서리·한글·조작 영역을 실행 가능한 UI의 정확한 픽셀 값으로 해석하지 않는다. 실제 구현 전에 이미지의 배치를 측정하고 320/390px와 넓은 임베드, 문 조작·재료 선택·등록·기록·지출·꾸미기의 실제 동작을 별도로 검증해야 한다.

특히 작은 영양제 등록 동작의44px 클릭 영역, 재료 추가 버튼과 하단 냉장고 문 조작의 겹침, 여러 제품·긴 이름·빈 상태를 구현 단계에서 확인한다. 현재 이미지에는 터치·저장·브라우저 검사 통과를 부여하지 않는다.
