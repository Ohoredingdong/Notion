## 버전 관리

- 최신 HTML에 실제 위젯 코드를 둡니다. 구버전 HTML을 불러와 화면을 조립하지 않습니다.
- 이전 주소의 HTML에는 최신 주소로 이동하는 작은 호환 파일만 둡니다. 기존 임베드의 쿼리 문자열과 해시를 유지합니다.
- 공유 CSS·JavaScript와 데이터 갱신 작업이 참조하는 자산은 함께 관리합니다.
- 브라우저 저장 키와 동기화 코드는 버전 정리 때 유지합니다. 이전 저장 기록을 지우지 않습니다.
- 과거 구현은 Git 커밋 기록에서 확인하고 복구할 수 있습니다.
