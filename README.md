## 갱신 방식과 확인 범위

- **시장 시세:** 각 수집 작업의 일정에 따라 저장하며, 화면 새로고침 시각과 실제 시세의 관측 시각을 구분합니다. 거래소·지표 제공처의 발표 지연과 휴장일을 포함합니다.
- **금리·부동산:** 한국은행 기준금리, 은행연합회 COFIX, 한국부동산원 주간 자료를 공식 출처에서 수집합니다. 금리는 발표된 기준금리이며 개별 은행의 대출 견적이 아닙니다. 부동산은 16지역/32개 현재 수치와 공식 날짜 열이 모두 검증되어야 교체합니다.
- **공급망:** GSCPI·ISM의 자동 수집을 복구했습니다. Drewry의 공개 최신 발표는 확인했지만 자동 요청에는 HTTP 429가 남아 있으므로 해당 항목은 갱신 지연으로 표시합니다.
- **기록·계산·학습:** 사용자 입력, 저장한 기록, 내장 학습 자료로 동작합니다. 실시간 외부 데이터가 없는 기능은 시간이 지났다는 이유만으로 갱신 오류로 분류하지 않습니다.
- **동기화:** 오류 응답·기존 기록 보존 분기를 검증했습니다. 실제 개인 연결 코드로 서버에 쓰는 동작은 이 점검에서 실행하지 않았습니다. 발음 재생은 기기의 음성 엔진에 따라 별도 확인이 필요합니다.
- **공식 공시 대조:** 미검증·기간 차이·수치 차이는 그대로 보여 줍니다. OpenDART 인증키가 필요한 경로의 설정 상태도 별도로 표시합니다.

작은 화면에서는 공통 설정 버튼이 화면 안에 들어오도록 보정했습니다. 크기·테마·잠금·초기화와 키보드 포커스도 확인했습니다.

## 자동 작업 복구

일반 시장 데이터 작업은 `scripts/publish_widget_data.py`로 최신 main에서 지정된 JSON만 저장합니다. 병렬 작업의 다른 위젯 변경을 보존하고, 같은 파일에 더 최신 자료가 있으면 덮어쓰지 않습니다. 부동산 수집의 잘못된 pip 캐시 설정을 제거했으며, 금리·부동산 수집이 실패하면 마지막 확인 자료를 유지하고 실패 상태를 별도 게시합니다.

회귀 검증은 실제 Git 저장소의 동시 push 충돌, 더 오래된 JSON의 덮어쓰기 방지, 공식 표의 날짜·지역 누락 거부, 통신 실패 때 기존 데이터 보존을 포함합니다. 개인용 Notion 첨부 위젯과 별도 Sites 앱은 이 공개 저장소 목록의 범위에 포함하지 않습니다.

## 버전 관리

- 최신 HTML에 실제 위젯 코드를 둡니다. 구버전 HTML을 불러와 화면을 조립하지 않습니다.
- 이전 주소의 HTML에는 최신 주소로 이동하는 작은 호환 파일만 둡니다. 기존 임베드의 쿼리 문자열과 해시를 유지합니다.
- 공유 CSS·JavaScript와 데이터 갱신 작업이 참조하는 자산은 함께 관리합니다.
- 브라우저 저장 키와 동기화 코드는 버전 정리 때 유지합니다. 이전 저장 기록을 지우지 않습니다.
- 과거 구현은 Git 커밋 기록에서 확인하고 복구할 수 있습니다.
